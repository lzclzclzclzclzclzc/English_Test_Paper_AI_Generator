# Skill: 思维导图

当用户想把某个语法/知识点讲解整理成思维导图时，按以下步骤执行。

## 触发条件

以下情形触发本 skill：
- "画个思维导图""用思维导图讲讲……""整理成脑图""做一张……的导图"
- 用户在思维导图编辑页要求修改当前这张图（如"把'易错点'再展开两条""加一个分支"）

以下情形**不触发**（交给其他 skill）：
- 用户要做题/练习/出卷 → 交给出题 skill（generate_paper）
- 用户要查例题 → 直接调用 get_example_questions

## 大纲格式

思维导图用层级 markdown 大纲表达（Markmap 格式）：
- `# 根节点`（导图主题，只能有一个）
- `## 分支`（一级分支，如 结构 / 用法 / 标志词 / 易错点）
- `- 叶子`（具体要点）

示例：
    # 现在完成时
    ## 结构
    - have/has + 过去分词
    ## 用法
    - 表经历
    - 表持续到现在
    ## 标志词
    - already / yet / ever
    ## 易错点
    - vs 一般过去时

## 执行步骤

### 情况 A：全局聊天里新建导图（没有"当前编辑的图"）

1. 根据用户主题，自己组织一份清晰的层级大纲 markdown（面向初中生，分支精炼）。
2. 调用 create_mindmap(topic, outline_markdown)。
3. 若返回 error，向用户说明并可重试；成功则按下方"输出格式 A"回应。

### 情况 B：编辑页里修改当前导图（系统已绑定当前图）

1. 先调用 get_current_mindmap 读取当前大纲，了解现状。
2. 按用户要求修改大纲（保留未提及的部分，只改用户想改的）。
3. 调用 update_current_mindmap(outline_markdown) 覆盖保存。
4. 若返回 error，向用户说明；成功则按下方"输出格式 B"回应。

（工具会自动使用当前登录用户与当前图，你不需要也无法指定用户ID或图ID。）

## 输出格式 A（新建）

🧠 已为你整理「{title}」的思维导图 👇

<mindmap_ready mindmap_id="（实际 mindmap_id）" />

不要解释这个标记，不要在它后面加任何文字。

## 输出格式 B（改图）

用一句话说明改了什么（如"已把'易错点'展开为 3 条"），然后另起一行输出：

<mindmap_updated />

不要解释这个标记，不要在它后面加任何文字。
