# Skill: 制定学习计划

当用户请求制定学习计划时，按以下步骤执行：

## Phase 1：输出自然语言计划

1. 调用 get_user_history 获取该用户的做题记录
2. 根据正确率分析薄弱知识点，把相关知识点组织成每天的"专题"：
   - accuracy < 0.4：严重薄弱，优先安排、多给题量
   - 0.4 ~ 0.7：需要巩固
   - accuracy > 0.7：已掌握，不纳入计划
   - 做题数 < 5：样本不足，仅做参考
   - **一天可以安排多个相关知识点（一个专题）**，也可以一个知识点单独一天；
     知识点相近的（如都属名词类）适合放同一天
   - **每一天排入的知识点都必须来自上方"题库知识点清单"中真实存在的条目**，
     且练习题型与该知识点所属题型一致。严禁编造清单外的考点（否则实施时会出卷失败）。
     若历史记录里的薄弱点不够，就从清单里挑其他知识点补充，而不是发明新考点。
3. 如果没有历史记录，告知用户暂无数据，建议先完成一套练习，然后停止
4. 对第 1 天要练习的知识点，调用 get_example_questions 获取 3 道例题
5. 输出完整的自然语言学习计划（见下方格式）
6. 在计划末尾提示用户如何实施

## 输出格式

📊 当前状况分析
- 已练习 X 道题，覆盖 Y 个知识点
- 严重薄弱（<40%）：知识点名 正确率%
- 需要巩固（40-70%）：知识点名 正确率%

📆 N 天学习安排
一天可以安排一个"专题"，包含多个相关知识点（例如"名词专题"含名词变复数、名词→动词等）：
第1天 | 名词专题 | 名词变复数、名词→动词、名词→动词（共 10 道）
第2天 | 形容词/副词专题 | 形容词→副词、形容词→名词（共 10 道）
...
最后1天 | 综合复习 | 混合前面的知识点

📝 第1天预习例题
[展示从题库获取的 3 道例题，包含题干、选项和答案]

每天总题量控制在 8~12 道；同一天的多个知识点必须都来自题库知识点清单。

---

💡 如需按此计划生成每日试卷，请告诉我"帮我实施这个计划"。

## Phase 2：实施计划（用户主动要求时）

当用户说"实施计划"、"帮我实施"、"生成试卷"、"按计划来"或类似意图时：

1. 找到当前对话上文中最近一次你输出的完整学习计划文本
2. 调用 implement_study_plan 工具，传入：
   - plan_text：上文中完整的学习计划文本
   - start_date：今天日期（YYYY-MM-DD 格式）
3. 工具成功后，告知用户计划已生成完毕，每天的试卷都已准备好，可以去"学习计划"页面查看并开始练习
4. 如果工具返回 error 字段，告知用户失败原因

（工具会自动使用当前登录用户，你不需要也无法指定用户ID。）
