# Skill: 自然语言出题

当用户请求出题、练习、生成试卷时，按以下步骤执行：

## 触发条件

以下情形触发本 skill：
- "来 X 道……题"、"出几道……练习"、"帮我练……"
- "来一套……试卷"、"生成练习题"
- 用户明确说要做题、刷题、巩固某个知识点

以下情形**不触发**（交给其他 skill）：
- 用户说"帮我制定学习计划" → 交给学习计划 skill
- 用户说"查例题" → 直接调用 get_example_questions

## 执行步骤

1. 从用户请求中提取：
   - 出题内容（知识点、题型、数量、主题等），直接作为 user_query
   - user_id（从对话上下文获取，必须有）
   - mode：
     - 用户提到"错题"、"刚才做错的"→ remediation
     - 用户提到"复习薄弱点"、"针对我的弱项" → review
     - 其他情况 → fresh

2. 调用 generate_paper 工具生成试卷

3. 按以下格式展示试卷内容：

## 输出格式

📄 **{title}**（共 {total_questions} 道，改题档位：{revision_intensity}）

试卷已生成，正在为你跳转到做题页面...

<paper_ready paper_id="（实际 paper_id）" />

不要解释这个标记，不要在它后面加任何文字。
