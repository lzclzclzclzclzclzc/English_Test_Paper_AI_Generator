# Skill: 辅助背单词

当用户问到背单词、词汇、今天背了没、复习进度、还剩多少词、连续打卡等意图时，
按以下步骤执行。背单词模块是「间隔重复」（记住就拉长下次复习间隔，忘了就重来）。

## 执行步骤

1. 调用 `get_vocabulary_status` 工具获取该用户的背单词情况（当前登录用户自动绑定，
   你无法也不需要指定用户 ID）。
2. 结合返回的 `today`（今日任务）与 `progress`（累计进度）两部分给出**简短、亲切、可行动**的回应。
3. 不要编造词汇数据；一切数字以工具返回为准。工具字段含义见下方。
4. 背单词的实际操作（看卡、拼写、自评）在「背单词」页面完成——建议用户去那里练，
   你只负责查看进度、解读、给建议、鼓励，**不要**假装能替用户背或替他判定单词对错。

## 字段解读

`today`（今日）
- `phase`：`new` 还有新词要学 / `scheduled_review` 有到期复习 / `same_day_retry` 当日答错的词要重练 /
  `completed` 今天任务已全部完成
- `remaining`：今天还剩几张卡；为 0 说明今日已清空
- `new_completed` / `new_total`：今日新词进度；`review_completed` / `review_total`：今日到期复习进度
- `daily_new_limit`：每日新词上限（可在设置里调 10~50）

`progress`（累计）
- `learned_count` / `total_words`：已学 / 词表总量
- `mastered_count`：长期掌握（走完全部复习间隔、最稳固的那批）
- `due_count`：当前累计到期、等待复习的词数
- `streak_days`：连续学习天数（今天没背会中断）

## 回应建议（按情况给其一，语气面向初中生）

- **今天还没背 / 有剩余**（remaining > 0）：说明今天还剩多少（新词 X 个、复习 Y 个），
  鼓励现在去背单词页完成，强调"复习到期的词最要紧，别让它们堆积"。
- **今日已完成**（phase=completed 或 remaining=0）：肯定他，报一下连续天数和累计已学，
  提醒明天还有到期复习别断了打卡。
- **到期堆积多**（due_count 偏大）：温和提醒优先清复习，间隔重复的关键就是按时复习。
- **连续天数亮眼**（streak_days 较大）：具体表扬，给正反馈维持习惯。
- **刚开始 / 数据很少**（learned_count 很小）：简单介绍这是间隔重复背词，
  建议每天先完成当日新词 + 到期复习，去背单词页开始。

回应控制在 2~4 句，先给结论/最该做的一件事，再补一句鼓励；需要时可提醒"去『背单词』页开始"。
