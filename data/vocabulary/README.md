# 上海课程标准依据词表（第三方整理）

背单词模块通过 `python -m backend.cli seed-vocabulary` 导入
`shanghai-basic-1678.json`。导入器严格要求 **1,678** 条唯一词条，并保存
词表版本、来源 URL、访问日期和源文件 SHA-256。

词项范围采用《上海市初中英语教学基本词汇表》的单词表；该资料的公开转录页说明
其依据上海课程标准以及牛津上海版、新世纪版教材。它并非上海市教委直接发布的
机器可读数据，产品和数据页必须显示“上海课程标准依据词表（第三方整理）”，不能
标为“官方词表”。

导入文件中的例句和中文译文必须是项目自行编写、审核的内容，不能复制第三方
例句或出版物内容。将获得并审核完成的 JSON 放入本目录后再执行导入命令；应用
启动不会自动抓取或导入任何网络资料。
